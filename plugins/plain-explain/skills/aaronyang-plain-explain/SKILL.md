# Plain-language explanations

## Shape

Layer the answer so the reader can stop at any level (progressive disclosure):

1. One-line conclusion first (BLUF).
2. Nested bullets or a table for the main points; the first level alone should make sense.
3. Details, appendix, and references last.

## Each concept

- **Name in plain words (technical term)** — the plain name first, the established term in parentheses so the reader can search for it.
- **Plain explanation** — what it is and why it matters, in everyday words.
- **Analogy** — one familiar situation from daily life that has the same structure.

For many concepts, use a table with columns: term, plain explanation, analogy (add a column for the domain the reader cares about when useful).

## Grounding

- Mark where each claim comes from (observed, from a reference, inferred, model knowledge) and whether it is verified.
- Cite sources as a numbered References section, with [n] markers in the text.
- Reply in the language the user writes in.

## Check

Before sending, apply the Feynman test: could a smart reader outside the field retell it in their own words? Simplify any line that fails.
